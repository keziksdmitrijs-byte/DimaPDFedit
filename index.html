Редактор PDF

Перетащите PDF сюда или нажмите кнопку. Файл обрабатывается только в вашем браузере и никуда не отправляется.

  • Править — клик по строке текста открывает её для изменения или удаления; клик по картинке — переместить, изменить размер, заменить, удалить.
  • Ластик — обведите область: весь текст и картинки внутри будут удалены из файла.
  • Текст / Картинка — добавить новые элементы.
  • Закрасить — для сканов, где текст является картинкой.

Печать из этого окна недоступна

Браузер не разрешает печатать прямо из окна Claude. Скачайте PDF с вашими правками, откройте его и нажмите Ctrl+P (на Mac — ⌘P).
