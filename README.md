# DimaPDFedit

Онлайн-редактор PDF, который работает целиком в браузере. Файлы никуда не отправляются: открытие, правка и сохранение происходят на вашем компьютере.

## Возможности

- **Правка текста** — клик по строке открывает её для изменения: текст, шрифт (Sans / Serif), размер, жирный, курсив, цвет. Поддерживаются кириллица и латышские буквы (ā, č, ē, ģ, ī, ķ, ļ, ņ, š, ū, ž).
- **Удаление текста** — строка действительно удаляется из файла (не закрашивается сверху), её больше нельзя найти поиском или скопировать.
- **Картинки** — выделить, переместить, изменить размер (за углы; Shift — без сохранения пропорций), заменить, удалить.
- **Ластик** — обведите область: весь текст и все картинки внутри удаляются.
- **Добавление** нового текста и картинок.
- **Закрасить** — заливка области цветом (для сканов, где текст является картинкой).
- Отмена / повтор (Ctrl+Z / Ctrl+Y), масштаб, повёрнутые страницы, многостраничные документы.
- **Скачать PDF** и **Печать** (Ctrl+P).

## Запуск

Это статический сайт без сборки. Нужен любой веб-сервер (из-за ES-модулей файл нельзя открыть просто двойным кликом):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

### GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`. Через минуту редактор будет доступен по адресу
`https://<пользователь>.github.io/DimaPDFedit/` — в обычной вкладке печать работает напрямую.

## Как это устроено

| Файл | Назначение |
|---|---|
| `index.html` | интерфейс и стили |
| `app.js` | логика редактора: страницы, выделение, панели, отмена, сохранение, печать |
| `engine.js` | разбор потоков содержимого PDF: находит каждый фрагмент текста и картинку с координатами и переписывает поток, чтобы по-настоящему удалить, переместить или заменить объект |
| `lib/` | [pdf.js](https://github.com/mozilla/pdf.js) 4.10 (отрисовка), [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17 (запись), [@pdf-lib/fontkit](https://github.com/Hopding/fontkit) (встраивание шрифтов); `cmapdata.js` и `stdfontdata.js` — CMap-таблицы и стандартные шрифты pdf.js, упакованные в JS |
| `fonts/` | Noto Sans и Noto Serif — шрифты для нового и изменённого текста |

После каждой правки документ пересохраняется и перерисовывается, так что на экране всегда видно ровно то, что окажется в файле.

## Ограничения

- Изменённый текст набирается шрифтом Noto, а не исходным: встроенные в PDF шрифты обычно содержат только использованные в документе буквы. Размер, цвет и положение сохраняются.
- Редактирование идёт построчно: абзац правится по одной строке.
- В сканах текста нет — только «Закрасить» + «Текст».
- Зашифрованные (защищённые паролем) PDF не открываются.
- Суммы и итоги в документах не пересчитываются автоматически.
